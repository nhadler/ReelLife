# Code of conduct

ReelTime follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be welcoming and respectful, assume good faith, accept
feedback gracefully, and keep criticism about the work, not the person.
Harassment, personal attacks and publishing others' private information
aren't tolerated.

It applies in the issue tracker, pull requests, discussions and anywhere
else you represent the project.

## Reporting

Report unacceptable behaviour privately to the maintainer, Nicholas
Hadler (GitHub: nhadler), through a private security advisory if
nothing else fits. Reports are kept confidential. The maintainer may
remove comments, close threads, or block people who break this code, as
the Covenant's enforcement guidelines describe.
